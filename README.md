### 📊 Sentiment Text Analysis

A full-stack NLP application that analyzes customer and social-media comments using a pretrained **Twitter-RoBERTa** sentiment model.

The application combines:

* FastAPI
* Pandas
* Hugging Face Transformers
* PyTorch
* Rule-based text refinement
* JavaScript
* Tailwind CSS
* Chart.js

It classifies comments as **Positive, Neutral, or Negative** and presents the results through an interactive analytics dashboard.

[**View Project →**](projects/sentiment-text-analysis/README.md)
